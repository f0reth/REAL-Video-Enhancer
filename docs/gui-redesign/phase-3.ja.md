# 工程3: 比較・調整機能

状態: 未着手  
目安: 5〜7日  
上位仕様: [GUI全面刷新計画](../gui-redesign-plan.ja.md)

## 目的と開始条件

工程2の編集画面と工程1の区間実行・直列制御が動作すること。

この工程の成果を次工程へ渡す。工程間で契約を変更した場合は、上位仕様と関係する工程計画・全呼び出し元を同時に更新する。

## 作業順序

1. 既定5秒の区間指定を入力尺へ制限し、同じ設定型・引数生成で専用出力へ試し書き出しする。本処理中は待機・取消を可能にする。
2. エンコード済み結果から静止フレームを抽出し、入力／処理後とA／Bの並列・境界比較を実装する。等倍・パン・倍率・位置を同期する。
3. 補間・スローモーションを入力時刻へ対応付ける。中間フレーム、区間境界、異なる解像度の拡大方法、HDRのトーンマップ条件を表示する。
4. 結果に設定・入力・区間を記録し、設定差分と旧設定の結果である表示を付ける。進捗用の最新画像と比較用の結果を区別する。
5. A／B保持・表示中・生成中を自動削除から保護する。保護されていない古い結果だけ削除し、上限で開始できない場合は保持解除・明示削除・上限変更を案内する。
6. 生成中の容量超過・空き容量不足では生成を取消し、新規部分ファイルだけを削除する。保持解除と削除を分け、既存A／Bを維持する。
7. 全体プリセットの保存・複製・削除・適用差分を実装する。入力・絶対出力先・GPU IDを除外し、最後に適用した設定と初期値への復帰を分ける。

## 成果物

短区間プレビュー、静止比較、A／B差分、容量管理、全体プリセット。

## 検証と完了条件

受け入れ条件1、3、4、8、16を確認する。補間・スローモーションで時刻と尺を検証し、小さい容量上限で保持結果が消えないことを確認する。本処理との設定一致を検証するが、区間境界によるビット単位一致は要求しない。

検証結果には対象環境・実施内容・結果・未解決事項を記録する。計画書の作成だけで実装や検証を完了扱いにしない。

## 対象外・共通制約

旧設定・プリセット・キャッシュの移行、互換ラッパー、恒久的な新旧GUI併存は行わない。ユーザー動画・モデル重みは削除しない。同期動画再生、キューの再起動復元、プリセット共有、複数GPU同時実行、自由な処理グラフは初版の対象外とする。
