# 工程2: 編集画面の作り直し

状態: 未着手  
目安: 6〜8日  
上位仕様: [GUI全面刷新計画](../gui-redesign-plan.ja.md)

## 目的と開始条件

工程1の最小実行経路と出力保護が動作すること。

この工程の成果を次工程へ渡す。工程間で契約を変更した場合は、上位仕様と関係する工程計画・全呼び出し元を同時に更新する。

## 作業順序

工程1の実装契約は [実装・検証記録](phase-1-results.ja.md) を参照。既存画面に接続済みの `RenderOptions`（動画・処理・エンコード・実行設定）と `Executor` を使用し、画面側でコマンド生成・モデル取得を再実装しない。

1. 小さなQt Widgetとレイアウトで主画面を構築する。QSplitter、折りたためる入力一覧、比較領域、スクロールする設定欄、常時表示の出力要約を配置する。
2. 動画ごとの編集状態を保持し、切替で他動画の設定を混同しない。入力情報と実効出力の解像度・FPS・尺を表示する。
3. Qtモデル／ビューによるモデル検索・絞り込み・詳細を実装する。導入済み・未導入・カスタムモデルを表示し、能力判定は基盤へ集約する。
4. 復元・補間・拡大・GPU設定を接続する。固定処理順、モデル倍率と最終倍率、補間倍率とFPSの関係、非対応理由を表示する。存在しない強度調整は追加しない。
5. CRF／CQ、速度、ProResプロファイル、画素形式、音声・字幕・コンテナの検証を接続する。エンコーダー変更時の値変更を明示し、実際のFFmpeg引数を読み取り専用表示する。
6. キュー追加と書き出すを同じジョブ確定経路へ接続する。上書き対象の確認と再確認待ちの解消操作を提供し、処理中の追加結果を明示する。
7. テーマ・フォーカス・日本語ラベル・変更済み表示を共通化する。試し書き出しと比較操作の配置を確定し、実機能は工程3へ接続する。

## 成果物

実行可能な新編集画面、モデル選択、数値設定、出力要約、共通表示定義。

## 検証と完了条件

受け入れ条件2、6、7、13と条件1の設定操作部分を確認する。モデル・エンコーダー変更で無効値を持ち越さず、編集中の変更が既存ジョブへ波及しない。1366×768で出力要約と操作ボタンが利用できる。

検証結果には対象環境・実施内容・結果・未解決事項を記録する。計画書の作成だけで実装や検証を完了扱いにしない。

## 対象外・共通制約

旧設定・プリセット・キャッシュの移行、互換ラッパー、恒久的な新旧GUI併存は行わない。ユーザー動画・モデル重みは削除しない。同期動画再生、キューの再起動復元、プリセット共有、複数GPU同時実行、自由な処理グラフは初版の対象外とする。
